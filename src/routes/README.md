# Routes

TanStack Start uses file-based routing. Each `.tsx` file in this directory
defines a route. The root layout is `src/routes/__root.tsx`.

| File         | URL                           |
| ------------ | ----------------------------- |
| `index.tsx`  | `/`                           |
| `__root.tsx` | app shell wrapping every page |

`routeTree.gen.ts` is generated by the router plugin. Do not edit it by hand.
